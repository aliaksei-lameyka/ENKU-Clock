# Hardware

This directory contains the canonical ENKU Clock Rev A hardware source.

- `mainboard/` — 4-layer Mainboard PCB
- `daughterboards/` — Encoder, Snooze and Wake LED PCBs
- `schematics/` — hierarchical Rev A schematic sheets
- `libraries/` — project-specific KiCad libraries
- `assembly/` — assembly BOM data
- `footprint-plan.csv` — footprint planning reference

Generated Gerbers and production archives are release artifacts, not hand-maintained source files.
